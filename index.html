ABOUT THE PROJECT

ⓘ
✦

Project overview

StudyFlow is a simple study-planning web application designed to help students organize subjects, manage study tasks, generate a weekly timetable, and track completion progress. The goal is to make study planning clear, practical, and easy to maintain.

Technology stack

  • Python and Flask
  • HTML5 and CSS3
  • JavaScript
  • SQLite database

Key features

  • Create and manage tasks
  • Mark tasks complete or delete them
  • Organize subjects and target hours
  • Generate a weekly study timetable
  • View task completion progress
  • Separate user accounts and password recovery
  • Responsive interface
